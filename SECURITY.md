# Security Policy

## Supported Versions

Only the latest stable release builds are supported with security patches.

## Reporting a Vulnerability

If you identify a security vulnerability in the KawaiiPhysics Unreal Engine plugin (such as crashes during compiled engine setups, memory alignment flaws, or script execution holes), please do **not** open a public issue.

Please report vulnerabilities privately by emailing the maintainers or using GitHub's private vulnerability reporting feature.
